# How-To Guides

Goal-oriented recipes for users who already know the basics. Each guide assumes a working
installation — if you do not have one, start with the [Quickstart](../tutorials/quickstart.md).

| Guide | Use it when |
| :---- | :---------- |
| [Install the D-Bus bridge](install-bridge.md) | `--diagnose` says the bridge is not installed or not running. |
| [Read a diagnostic result](diagnose.md) | Something does not work and you want to know which layer refused. |
| [Allow or block a device, for now or for good](device-actions.md) | You are choosing between *this session only* and *permanently*. |
| [Add and remove rules safely](rules.md) | You are editing the policy, possibly while something else edits it too. |
| [Change policy with your own password](polkit-rule.md) | Typing the administrator password for every change is too much. |
| [Keep announcing devices with the window closed](background.md) | You want notifications without keeping the window open. |
| [Report a bug without leaking your hardware](bug-report.md) | You are about to open an issue. |
